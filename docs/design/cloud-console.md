# 云端控制台与运营后台

> 状态：目标设计（2026-10-23，U0，Refs AMA-Link/armadra-cloud#60）。能力、角色与分期以 armadra-cloud 的 `docs/design/saas-design.md`（下称「能力设计」）为准，过程名、事件与错误码以协议 1.4 的最终契约为准（armadra-cloud#63，`cloud-api.md` §21–§32）；本文只定 `apps/web` 里「云端」分区与运营后台的页面、组件、文案、数据层与批次。视觉一律遵守[设计系统](design-system.md)，展示与截图走[设计展示页](design-showcase.md)，客户端侧栏沿用[远程访问重设计](remote-access-redesign.md)。
> 硬性规则：极简，不写说明性文字，不出现「预留 / 未实现」，chrome 里不放版本与状态字符串；文案只用简体中文（品牌与 CLI 名除外），全部经 `apps/web/src/i18n/` 且中英同步；只用 `apps/web/src/ui/` 的现有 shadcn 组件；功能代码里不手写 `<button className>`。

## §0 结论

| #   | 决定                                                                                                                                                                                                                                                                       | 依据                           |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------ |
| 1   | 控制台是 `apps/web` 的第五种入口 `console`，由 `app.armadra.com` 托管；不进桌面壳、服务器壳与手机 App 的产物路径                                                                                                                                                           | 能力设计 §8、Q6                |
| 2   | 不引入路由库：`apps/web/src/cloud/router.ts` 用 History API + 一张类型化路由表（约 80 行），地址是唯一真相                                                                                                                                                                 | 现有代码没有路由库；包体       |
| 3   | 不新增 shadcn 组件：导航沿用设置页的 `settings-navigation` 样式，空间切换用 `DropdownMenu`，选人用 `Popover` + `Command`，配额用 `Progress`（U1a 给 `ui/progress.tsx` 按 shadcn 的 cva 写法加 `tone` 变体：`default` / `warn` / `danger`，只改指示条颜色），图表用 `chart` | 设计系统 §3.2「不加」清单      |
| 4   | 一份列定义两种渲染：≥768 渲染 `Table`，≤767 渲染 `Item` 列表，次要列折进第二行 11px                                                                                                                                                                                        | 设计系统 §5.13；TUI §1 第 7 条 |
| 5   | 主机的工作空间范围授予只在客户端分享弹层里做；控制台的授予范围只有「整台」；按标签授予等契约补上（§6.5）                                                                                                                                                                   | 云端看不到工作空间列表         |
| 6   | 运营后台同源同构建，路径 `/ops`；没有运营会话的人访问 `/ops/*` 一律整页「找不到这个页面」，不暴露这一区（§1.4）                                                                                                                                                            |
| 7   | 数据层：协议包 `cloudContract` + `OpenAPILink` 生成类型化客户端；同类型的内存 mock 先行，界面不等 Go 控制面                                                                                                                                                                | 能力设计 §7；Go 重写 G6        |

## §1 范围与落点

### 1.1 与现有界面共存

| 宿主                           | 打开什么                                                         | 云端相关的部分                                                                                                  |
| ------------------------------ | ---------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| `app.armadra.com`              | 控制台（本文）、`/h/<hostId>` 画布、`/j/`、`/device`、`/invite/` | 全部页面；画布经 `browser-cloud` 凭据提供方连主机                                                               |
| 个人中转托管的页面（中转来源） | 现有：`/j/` 落地页与托管画布                                     | 不变；`platform.info.mode = personal` 时不出现控制台                                                            |
| 桌面壳 / 服务器壳              | 画布                                                             | §3.5 的客户端触点：添加连接、登记主机到空间、分享弹层、待信任设备、侧栏按团队分小组；「打开控制台」用系统浏览器 |
| 手机 App                       | 画布与连接页                                                     | 只做查看与处理（访问申请、邀请、设备信任）；管理类入口打开网页                                                  |

### 1.2 入口判定

`mobile/entry.ts` 的 `Entry` 加一种 `{ kind: "console"; path: string }`：

| 条件（按顺序）                                                                                         | 入口                                  |
| ------------------------------------------------------------------------------------------------------ | ------------------------------------- |
| 路径 `/app/challenge`                                                                                  | 现有挑战页                            |
| `GET /.well-known/armadra-platform` 的 `mode = saas` 且 `webApp = location.origin`，路径 `/h/<hostId>` | 现有 App，凭据提供方 `browser-cloud`  |
| 同上，路径 `/j/<linkId>`                                                                               | 现有 `JoinPage`（加 SaaS 分支，§3.1） |
| 同上，其余路径                                                                                         | `console`                             |
| 其余                                                                                                   | 现有分支不变                          |

### 1.3 鉴权

| 项           | 规则                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 控制台会话   | `__Host-armadra-cloud` Cookie（能力设计 §11.6）；页面不读不存令牌                                                                                                                                                                                                                                                                                                                                                                             |
| 写操作       | 每个非 GET 带 `X-Armadra-CSRF`：值取自 `auth.login` / `auth.mfaVerify` / `auth.refresh` 响应的 `csrfToken`，页面刷新后由 `me.get` 的 `csrfToken` 取回，只在内存（契约缺口，§6.5）；同一请求不同时带 Cookie 与 Bearer                                                                                                                                                                                                                          |
| 401          | `unauthenticated` / `session_expired` / `session_revoked` → 清查询缓存，跳 `/login?next=<当前路径>`                                                                                                                                                                                                                                                                                                                                           |
| 到主机的访问 | `sources/credentials.ts` 新增 `createBrowserCloudCredentialProvider()`：用 Cookie 会话调 `sources.assertion`，断言与中继令牌只在内存，关标签即丢                                                                                                                                                                                                                                                                                              |
| 运营范围     | 进 `/ops` 必须全新登录：`/login?scope=operator&next=/ops`，口令 + 两步验证，`auth.login { scope: "operator" }` 签出**另一个** Cookie `__Host-armadra-ops`（不覆盖 `__Host-armadra-cloud`，1 小时，只对 `admin.*` 与它自己的登出 / 刷新有效，CSRF 值随这次登录另给一份）；运营账号没开两步验证 → `operator_mfa_required`（403），非运营账号 → `forbidden`；过期回这一步。M1 不做「在已有会话上再验证」（`auth.stepUp`，G1）；运营 Cookie 是 G2 |
| CSP          | 控制面下发，`connect-src` 覆盖 `*.src.armadra.com`；页面不内联脚本                                                                                                                                                                                                                                                                                                                                                                            |
| 支持         | 「联系支持」是 `mailto:`，地址来自构建配置 `VITE_ARMADRA_SUPPORT_EMAIL`（`cloud/config.ts`），缺省不渲染这个按钮                                                                                                                                                                                                                                                                                                                              |

## §3 页面

### 3.0 通用约定

| 项     | 规则                                                                                                                                                                                                                                                                                                                                  |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 加载   | 无数据时用 `ui/skeletons`（`SkeletonTable` / `SkeletonList` / `SkeletonSettings` / `SkeletonForm`），<200ms 不显示，显示后至少 300ms；有缓存先显示缓存                                                                                                                                                                                |
| 空     | `EmptyState`：一句名词短语 + 至多一个 default 动作                                                                                                                                                                                                                                                                                    |
| 错     | 整页：`cloud/ui/PageState.tsx`（U1a，`Empty` + 一句标题 + 一个 `Button`），五种：按 `code` 的错误 +「重试」、没有权限（`forbidden` / `team_policy_denied`）+「回到概览」、找不到 +「回到概览」、维护中（`unavailable` / `storage_unavailable`）+「重试」、登录已过期 +「重新登录」；现有 `ErrorState` 只用在行内与区块内；行内动作失败 → sonner（带动作的错误常驻到关闭）；表单 → `Field` 下方一行 |
| 权限   | 没权限的动作不渲染；角色只读的值用文字代替 `Select`；不写「你没有权限」                                                                                                                                                                                                                                                               |
| 实时   | me-stream 事件只失效对应查询键（§6.2），不整页重载                                                                                                                                                                                                                                                                                    |
| 行动作 | 行尾最多一个 ghost 动作，其余收进 `DropdownMenu`（`MoreHorizontal`，`aria-label`「{名称} 的操作」）                                                                                                                                                                                                                                   |
| 时间   | 相对时间（`Intl.RelativeTimeFormat`），悬停 `Tooltip` 给绝对时间；数字列 `tabular-nums` 右对齐                                                                                                                                                                                                                                        |

## §4 视觉细节

### 4.1 密度与形态

| 决定               | 规则                                                                                                                                                                  |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 密度               | 与设置页同档：行高 44（设置行 min 48）；带第二行的列表行（主机表的名称 + 所有者 / 权限）是唯一例外，52；正文 13，次要 11；页面左右 32 / 24 / 16（桌面 / 平板 / 手机） |
| 表格 vs 卡片       | 可比较、可排序的同类对象（主机、成员、授予、链接、审计、令牌、节点、租户）→ `Table`；数量 ≤ 4 的摘要（统计、计划）→ `Card`；设置 → `SettingsGroup`                    |
| 一份列定义两种渲染 | `cloud/ui/DataList.tsx` 接收列定义（`primary` / `secondary` / `trailing`），≥768 画 `Table`，≤767 画 `Item`；同一份数据、同一组行动作                                 |
| 层级               | 靠留白与缩进：组间 24、组内 8、展开行缩进 16；不加额外分隔线（`Table` 自带行线除外）                                                                                  |
| 一屏一个主动作     | 页头至多一个 default；对话框里主动作在右、取消在左                                                                                                                    |
| 一屏彩色 ≤ 3       | 品牌（选中、主按钮）+ 至多两种状态色；角色、标签、计划一律中性 `Badge`                                                                                                |

- 一律用 `panels/ResponsiveDialog.tsx` 的 `ResponsiveAlertDialog*`（手机上自动是底部形态）；功能代码不直接用 `ui/alert-dialog`（`no-raw-alert-dialog` 守卫）。

### 4.4 Toast（sonner）

| 情形         | 形态                                            |
| ------------ | ----------------------------------------------- |
| 行内动作成功 | 一句过去式「已撤销」「已邀请 {count} 人」，4 秒 |
| 可撤回       | 带「撤回」动作，5 秒                            |
| 行内动作失败 | 按 `code` 取文案 + 「重试」，常驻到关闭         |
| 表单错误     | 不用 toast，`Field` 下方                        |
| 读屏         | sonner 的 `role="status"`；错误不抢焦点         |

### 4.5 响应式

| 宽度     | 外壳                       | 列表                                          | 对话框                                     |
| -------- | -------------------------- | --------------------------------------------- | ------------------------------------------ |
| ≥1024    | 侧栏 240 固定              | `Table`                                       | `Dialog` 520 / `ResponsiveAlertDialog` 420 |
| 768–1023 | 顶栏 48 + `Sheet left` 280 | `Table`（次要列按容器宽度隐藏，内容进行展开） | 同上                                       |
| ≤767     | 顶栏 48 + `Sheet left` 280 | `Item`                                        | `Sheet bottom`（`ResponsiveDialog`）       |

- `ui/table` 自带 `overflow-x-auto` 外层，保留；靠列数控制（主机表 5 列）与容器查询收列，使 320 宽与 200% 缩放下正常数据不出现横向滚动。确有页面要禁止滚动时，U1a 再给 `Table` 加一个不滚动的变体。

### 4.6 深浅主题

- 只用 `tokens.css` 的语义 token，不写 `dark:`；主题取 `armadra.theme`（与 App 共用），账号菜单里可切：跟随系统 / 浅色 / 深色。
- `<html>` 写 `color-scheme`，`<meta name="theme-color">` 跟 `--bg`；切换主题时按 better-ui 的配方临时关过渡。
